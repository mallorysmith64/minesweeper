# Welcome to Minesweeper! :smiley:

Objective: Full-stack application for minesweeper

Technologies Used: React.js, Javscript, Flask, Python, Railway (hosting site for backend), CSS Flexbox, HTML5

To run this project locally:
git clone </br>
cd minesweeper </br>
npm init </br>
npm install </br>
npm run dev (runs both the frontend and backend concurrently) </br>

Cheers.
